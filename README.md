# Chinook SQL Portfolio

## Project Overview

This project contains SQL queries and analyses performed on the Chinook database using PostgreSQL.

The goal of this project is to practice SQL skills by solving business problems related to sales, customers, employees, and music tracks.

## Database

The Chinook database represents a digital music store, containing information about:

* Customers
* Employees
* Invoices
* Artists
* Albums
* Tracks
* Genres

## Skills Demonstrated

* SELECT statements
* Filtering with WHERE
* JOINs
* GROUP BY and aggregation
* ORDER BY
* Subqueries*
* Common Table Expressions (CTEs)*
* Window Functions*

## Business Questions

Examples of problems solved in this project:

1. Find the 10 most purchased tracks by total quantity sold.
2. Calculate total invoice revenue for each billing country.
3. List all customers where the phone field is NULL.
4. Find all tracks with a duration over 300,000 milliseconds.
5. Retrieve all albums for Aerosmith
